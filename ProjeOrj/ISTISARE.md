# ISTISARE - MHaydiNamaza

## Faz Taslaklari (uygulamaya gecmeden once)

- Faz 0: Kapsam, hedef kitle, platform min surumleri, veri kaynaklari, dil listesi.
- Faz 1: Python algoritmanin Dart portu ve altin test seti.
- Faz 2: Veri katmani, cache, offline/online kurallari, timezone/DST.
- Faz 3: Temel UI, navigasyon, erisilebilirlik, tema.
- Faz 4: Bildirim, alarm, sesli okuma, arka plan kurallari.
- Faz 5: Kisisellestirme, hesaplama metodu, ofsetler, favoriler.
- Faz 6: Performans, batarya, bellek, hata yakalama.
- Faz 7: Dagitim, CI/CD, store hazirligi, release notlari.
- Faz 8: Operasyon, guncelleme stratejisi, geri bildirim toplama.

## Gereksinimler (detayli ozet)

- Dogruluk: Farkli hesaplama yontemleri, kaynaklar arasi tutarlilik.
- Zaman/konum: Timezone/DST, manuel konum, GPS fallback.
- Offline: Son gecerli veri + lokal hesaplama, veri gecerlilik politikasi.
- Online: API ile periyodik guncelleme, hata/timeout stratejisi.
- Bildirim: Sessiz/sesli, tekrar araligi, test modu, snooze.
- Ses: Yerel ses, tts, ezan secimleri, cihaz profilleri.
- UI/UX: Hizli acilis, erisilebilirlik, tek elle kullanim, tema.
- Performans: Isolate/arka plan, minimal batarya, baslangic optimizasyonu.
- Gizlilik: Minimum izin, lokasyon veri saklama, acik riza metni.
- Store: Izin aciklamalari, gizlilik politikasi, release notlari.
- Surumleme: Geri uyumluluk, migration stratejisi.
